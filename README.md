# Dynamic Gallery
About the Project

This project is a Dynamic Gallery created using HTML and CSS. It displays multiple images in four columns using CSS Flexbox.
# Features
Displays multiple images in a gallery layout.
Four columns arranged using Flexbox.
Images are displayed at full column width.
Simple and attractive layout.
Easy to understand HTML and CSS code.
# Technologies Used
HTML5
CSS3
Flexbox
# Project Structure
index.html – Contains the HTML structure and CSS styling.
Capture 1.PNG – Gallery image.
Pyramid of Giza.png – Gallery image.
window.png – Gallery image.
nightview.png – Gallery image.
# How to Run
Keep all image files in the same folder as the HTML file.
Open the HTML file in a web browser.
The Dynamic Gallery will be displayed.
# Purpose

The purpose of this project is to learn how to create an image gallery using HTML, CSS, and Flexbox.
